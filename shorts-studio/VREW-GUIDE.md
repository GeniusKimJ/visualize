# 브루(Vrew) 초보자용 쇼츠 제작 가이드

> Vrew는 업데이트가 잦아 메뉴 이름·위치가 조금씩 바뀝니다. 이름이 다르면 "무엇을 하는 버튼인지"를 기준으로 찾으세요.
> 회차별 상세 지시는 `episodes/<회차>/vrew.md`에 따로 만들어집니다.

## 빠른 길 — 작업 카드로 복사만 하기
회차 폴더의 `vrew-pack/index.html`을 PC 브라우저(또는 휴대폰)로 엽니다. 위에서부터:
1. **대본 복사** → Vrew 새로 만들기 → 텍스트로 비디오 만들기 → 쇼츠 9:16 → 붙여넣기 → AI 목소리 선택
2. **장면별 AI 이미지 문구 복사** → 해당 장면 이미지 바꾸기 → AI 이미지에 붙여넣기
3. **큰 글자 복사** → 해당 장면에 텍스트 추가 (0초 장면은 애니메이션 없이)
4. 배경음악 고르기 → 내보내기 mp4
5. **제목·설명란·고정댓글 복사** → 업로드, 페이지 맨 아래 체크리스트 확인

> 작업 카드는 사실 검증과 업로드 전 점검을 통과한 회차에만 만들어집니다. 아래는 각 단계를 자세히 설명한 내용입니다.

## 0. 준비
- Vrew 설치 후 로그인 (무료 요금제는 AI 목소리·AI 이미지 사용량과 내보내기 옵션에 제한이 있을 수 있음)
- `episodes/<회차>/script.md`에서 **팩트체크를 통과한 최종 원고**의 'Vrew 붙여넣기용 순수 원고' 블록을 복사해 둡니다.
  수정 이력이 있는 회차는 최신 원고가 맨 위에 있고, 아래쪽은 반려된 옛 원고이니 복사하지 마세요.

## 1. 새 프로젝트 — 텍스트로 비디오 만들기
1. **새로 만들기** → **텍스트로 비디오 만들기**
2. 화면 비율 **쇼츠 9:16** 선택
3. 비디오 스타일을 고르고 다음으로
- 자주 하는 실수: 16:9로 만들어 놓고 나중에 바꾸면 자막·이미지 배치가 전부 틀어집니다. 처음부터 9:16.

## 2. 대본 넣기
1. 대본 입력 칸에 순수 원고를 붙여넣습니다. 문장마다 줄바꿈 → 한 줄이 한 장면·한 자막이 됩니다.
2. 원고 위쪽의 인사말이나 장면 번호가 같이 붙지 않았는지 확인합니다.
- 자주 하는 실수: 장면표 전체를 붙여넣어 "[장면1]" 같은 글자까지 읽어 버리는 경우.

## 3. AI 목소리
1. 목소리 목록에서 차분한 중년 톤을 미리 듣기로 비교해 하나 고릅니다.
2. 속도는 0.9~1.0배 (중장년 시청자는 너무 빠르면 이탈합니다).
- 자주 하는 실수: 장면마다 목소리가 다르게 들어가는 경우 → 전체 적용으로 한 번에 바꾸세요.

## 4. 장면 이미지
- 장면마다 **무료 이미지/영상** 또는 **AI 이미지**를 고릅니다. `vrew.md`의 검색 키워드를 그대로 쓰세요.
- 사람 얼굴이 크게 나오는 이미지는 자막 위치를 따로 조정해야 합니다.
- 자주 하는 실수: 인터넷에서 아무 이미지나 내려받아 넣기 → 저작권 문제. Vrew 제공 소재나 AI 이미지만 쓰세요.

## 5. 자막
- 위치: 화면 아래쪽 1/3 위. **맨 아래와 오른쪽 끝은 비워 두세요** (쇼츠 화면의 제목·채널명·좋아요 버튼이 덮습니다).
- 크기: 휴대폰에서 읽힐 만큼 크게, 한 줄 12자 이내.
- 색: 기본색(흰 글자 + 검은 테두리) + 강조색 1개(노랑 등). 박스·이모지 남발 금지.
- 얼굴이나 표·숫자 화면이 나오는 장면은 자막을 위로 옮겨 가리지 않게 합니다.
- 자주 하는 실수: PC 화면에서는 커 보여도 휴대폰에서는 작습니다. 꼭 휴대폰으로 확인.

## 6. 첫 장면 큰 제목 (후킹)
- 첫 장면에 후킹 문구를 **큰 텍스트**로 넣고 0초부터 보이게 합니다.
- 자주 하는 실수: 제목이 1초 뒤에 나타나게 애니메이션을 넣는 경우 → 0초에 바로.

## 7. 배경음악(BGM)
- **YouTube 오디오 보관함** 음원, 또는 Vrew 제공 음원 중 라이선스(상업 이용 가능 여부, 출처 표기 조건)를 확인한 것만 사용합니다.
- 볼륨은 나레이션보다 훨씬 작게 (대략 10~15% 수준).
- 사용한 음원 이름과 조건을 `vrew.md` 음원 기록란에 적어 둡니다 (설명란 출처 표기용).
- 자주 하는 실수: 좋아하는 가요·트로트를 배경에 깔기 → 차단되거나 수익이 원저작자에게 갑니다.

## 8. 군더더기 자르기
- 장면 사이 무음, 말 끊김을 지웁니다. 첫 장면은 지연 없이 바로 나레이션이 시작되게.
- 미리보기로 전체 길이 30~60초인지 확인합니다.

## 9. 내보내기
- **내보내기** → **영상 파일(mp4)**, 해상도 1080x1920.
- 휴대폰으로 옮겨 한 번 끝까지 재생해 봅니다 (글자 크기, 자막 가림, 소리 크기).

## 10. 업로드
- `upload.md`의 제목·설명·해시태그·고정댓글을 그대로 사용합니다.
- 업로드 후 YouTube Studio → 해당 영상 → **저작권 주장** 여부 확인.
- 조회수가 낮아도 **삭제하지 마세요**. 문제가 있으면 비공개로 돌리고 원인을 분석합니다.

## Vrew 편집 (10~15분)
1. 새로 만들기 → 텍스트로 비디오 만들기 → 쇼츠 9:16
2. 대본 칸에 작업 카드의 대본 붙여넣기 — **'AI 글쓰기'는 누르지 않기** (AI 글쓰기 Pro 스위치 끄기)
3. AI 목소리(차분한 중년, 0.9~1.0배) → '이대로 완료하기' ('AI 비디오로 만들기' 아님)
4. Ctrl+A → 서식에서 자막 크기 60~70%로, 단어 중간에서 끊긴 줄만 Enter로 나누기 (단어는 바꾸지 않기)
5. 어색한 장면만 작업 카드의 'AI 이미지 문구'로 이미지 바꾸기
6. 1번 클립 → 삽입 → 이미지 → `title-overlay.png` → 화면 전체 크기, 1번 클립만 (`title-preview.png`는 넣지 않기)
7. 삽입 → 배경 음악(작게, 곡 이름 메모) → 내보내기 mp4

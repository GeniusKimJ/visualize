# 숫자 카드 스타일 — 숫자는 표 한 장으로

렌더러: `shorts-studio/tools/make_number_card.js` · 예시: `episodes/2026-10-31-50세이상-실업급여/vrew.md`

말로만 들으면 숫자가 머리에 남지 않습니다. 기간·금액·비율·조건을 비교하는 장면은 AI 이미지 대신 **표 한 장(1080×1920)**을 화면 전체로 보여줍니다.
모든 회차에 숫자 카드를 **1장 이상** 넣습니다 (보통 1장, 많아도 2장).

## 구성
| 요소 | 규칙 |
|---|---|
| 배경 | 분야별 색 (건강 노랑, 재테크 연두, 노후 준비 금색, 여행 하늘, 생활정보 주황, 최신 이슈 빨강) |
| 제목 | 2줄. 1줄은 남색 큰 글씨(무엇), 2줄은 남색 띠 위 흰 글씨(어떻게 나눠 봤는지). 한 줄 10자 안팎 |
| 표 | 열 2~4개, 행 3~7개 (최대 10). 첫 열은 구분, 시청자가 볼 열은 `강조열`로 파랗게 |
| 칸 글자 | 한 칸 12자 안팎. 길면 글자가 자동으로 줄어들고, 그래도 넘치면 두 줄 |
| 주석 | 1~2줄. 조건·단점 한 줄 + 출처(기관명). 계산 예시면 "○○은 계산 예시"라고 적는다 |
| 아래 여백 | 1480px 아래는 비워 둔다 (Vrew 자막·쇼츠 버튼 자리) |

## vrew.md에 넣는 블록
`vrew-scenes` 블록 바로 아래에 둡니다.

```vrew-numbers
[
 {
  "장면": [5, 6, 7, 8, 9],
  "제목": "실업급여 받는 기간\n나이·가입기간별",
  "열": ["고용보험\n가입기간", "50세 미만", "50세 이상"],
  "행": [["1년 미만", "120일", "120일"], ["10년 이상", "240일", "270일"]],
  "강조열": 2,
  "강조행": [2],
  "주석": "나이는 퇴직한 날 기준\n출처: 고용노동부·정책브리핑"
 }
]
```
- `장면`: 이 카드를 보여줄 vrew-scenes 장면 번호 (나레이션이 표 내용을 짚는 구간)
- `강조열`: 0부터 센 열 번호 · `강조행`: 1부터 센 행 번호 (선택)

## 좋은 숫자 카드
- **비교가 보이게**: 구간별(나이·기간·연차), 전후(미루면 얼마), 조건별(이하/초과). 예: 근무연수별 세금, 연기 기간별 증가율, 가입기간별 일수
- **계산 예시는 환영**: "월 100만 원이라면 → 136만 원"처럼 검증된 비율에 쉬운 기준 금액을 넣어 계산해 보여준다. 계산 과정은 factcheck.md '숫자 카드 검증'에 적는다
- **오래 맞는 숫자**: 비율·일수·나이·조건처럼 잘 안 바뀌는 숫자를 쓴다. 해마다 바뀌는 금액(연금액·상한액·보험료)이 표의 중심이면 안 된다

## 지킬 것 (렌더러가 검사하고, 어기면 만들지 않음)
- 카드의 모든 숫자는 `factcheck.md`에 있어야 한다 → 계산값도 '숫자 카드 검증' 절에 계산식과 함께 기록
- 시기 표현 금지: 지금·요즘·이번 주/달·올해·내년·오늘부터·새로 바뀐·연도·날짜 (기준일 표기도 넣지 않는다)
- 열 4개, 행 10개, 제목 2줄을 넘지 않는다

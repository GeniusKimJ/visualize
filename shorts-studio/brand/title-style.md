# 채널 강조 제목 스타일 — "배경 없는 두 줄"

견본: [title-style.html](title-style.html) · 렌더러: `shorts-studio/tools/make_title_card.js`

배경 띠 없이 글자만 이미지 위에 얹는 스타일입니다. 어떤 사진 위에서도 읽히도록 굵은 검은 테두리와 그림자로 강조합니다.

## 구성 (1080×1920, 화면 위쪽 200px부터)
| 요소 | 규칙 |
|---|---|
| 태그 | 강조색 바탕 + 검은 글자, 6자 이내, 시기·대상 (예: `2026년 대상`, `11월부터`) |
| 1줄 | 흰색, Black Han Sans, 18px 검은 테두리 + 아래 그림자. 누구 얘기인지 (예: `짝수년생 건강검진`) |
| 2줄 | 강조색, 같은 글꼴·테두리. 핵심 숫자나 행동 (예: `12월 31일까지`) |
| 크기 | 150px에서 시작해 화면 폭(980px)에 맞게 자동 축소, 최소 96px → 한 줄 9자 안팎 권장 |
| 서명 | 기본은 없음. `make_title_card.js`의 `CHANNEL`에 채널명을 넣으면 2줄 아래 작은 흰 글자로 표시 |

## 분야별 강조색 (태그·2줄)
| 테마 | 강조색 |
|---|---|
| 건강 | 노랑 `#FFD62E` |
| 재테크 | 연두 `#7CF08A` |
| 노후 준비 | 금색 `#FFB547` |
| 여행 | 하늘 `#7FD8FF` |
| 생활정보 | 주황 `#FF8A3D` |
| 최신 이슈 | 빨강 `#FF5A5A` |

예전 이름(돈·생활·여가)도 각각 재테크·생활정보·여행으로 처리됩니다.

## 쓰는 법
1. `vrew.md`의 `vrew-scenes` 1번 장면에 `큰글자`(줄바꿈으로 2줄), `태그`, `테마`를 넣는다.
2. `node shorts-studio/tools/make_title_card.js <회차폴더>` → `vrew-pack/title-overlay.png`(투명), `title-preview.png`
3. Vrew 1번 장면에 `title-overlay.png`를 화면 전체 크기로 맨 위에 얹는다.
4. 1번 장면 AI 이미지는 위쪽 1/3이 너무 복잡하지 않은 것(하늘, 벽, 흐린 배경)을 고르면 글자가 더 잘 보인다.

## 지킬 것
- 제목 카드에 쓰는 사실은 팩트체크를 통과한 문구만 쓴다.
- "충격", "경악", 물음표·느낌표 남발 같은 낚시 표현을 쓰지 않는다. 강조는 색과 크기로만 한다.
- 2줄을 넘기지 않는다. 길면 문구를 줄인다 (글자를 더 줄이지 않는다).

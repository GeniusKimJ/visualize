# 채널 강조 제목 스타일 — "꽉찬 두 줄"

견본: [title-style.html](title-style.html) · 렌더러: `shorts-studio/tools/make_title_card.js`

## 구성 (1080×1920, 위쪽 700px 밴드)
| 요소 | 규칙 |
|---|---|
| 밴드 | 분야색 세로 그라데이션 + 아래 14px 강조색 줄 + 왼쪽 22px 강조색 세로 띠 (채널 고유 표시) |
| 태그 | 강조색 바탕 + 밴드색 글자, 6자 이내, 시기·대상 (예: `2026년 대상`, `11월부터`) |
| 1줄 | 흰색, Black Han Sans, 누구 얘기인지 (예: `짝수년생 건강검진`) |
| 2줄 | 강조색, 같은 글꼴, 핵심 숫자나 행동 (예: `12월 31일까지`) |
| 크기 | 150px에서 시작해 밴드 폭(960px)에 맞게 자동 축소, 최소 96px → 한 줄 9자 안팎 권장 |
| 서명 | 밴드 오른쪽 아래 채널명 (`make_title_card.js`의 `CHANNEL`) |

## 분야별 색
| 테마 | 밴드 | 강조색 |
|---|---|---|
| 건강 | 남색 `#0B1A44 → #17306E` | 노랑 `#FFD62E` |
| 돈 | 짙은 초록 `#06352A → #0E5541` | 금색 `#FFC93C` |
| 생활 (사기예방 등) | 버건디 `#4A0B12 → #7A1420` | 밝은 노랑 `#FFE14D` |
| 여가 | 보라 `#2B1048 → #4A1F7A` | 노랑 `#FFD62E` |

## 쓰는 법
1. `vrew.md`의 `vrew-scenes` 1번 장면에 `큰글자`(줄바꿈으로 2줄), `태그`, `테마`를 넣는다.
2. `node shorts-studio/tools/make_title_card.js <회차폴더>` → `vrew-pack/title-overlay.png`(투명), `title-preview.png`
3. Vrew 1번 장면에 `title-overlay.png`를 화면 전체 크기로 맨 위에 얹는다. 밴드 아래로 AI 이미지가 보인다.

## 지킬 것
- 제목 카드에 쓰는 사실은 팩트체크를 통과한 문구만 쓴다.
- "충격", "경악", 물음표·느낌표 남발 같은 낚시 표현을 쓰지 않는다. 강조는 색과 크기로만 한다.
- 2줄을 넘기지 않는다. 길면 문구를 줄인다 (글자를 더 줄이지 않는다).

# Shorts Studio — 5060 중장년 유튜브 쇼츠 제작 시스템

50~60대 남녀 공통 관심 키워드로 30~60초 쇼츠를 만들고, 수익화까지 이어가기 위한 작업 폴더입니다.
편집은 브루(Vrew)로 하고, 기획·원고·사실 검증·업로드 문구는 Claude 서브에이전트가 나눠 맡습니다.

## 사용법
Claude Code에서 이 저장소를 연 뒤:

```
/shorts                 # 이번 주 트렌드 조사부터 시작
/shorts 기초연금 45     # 주제와 길이를 정해서 시작
```

결과물은 `episodes/<날짜>-<주제>/`에 저장됩니다. 검증·점검을 통과하면 `vrew-pack/index.html`(복사 버튼이 달린 Vrew 작업 카드)이 자동으로 만들어집니다.
수동으로 다시 만들려면 `python3 shorts-studio/tools/make_vrew_pack.py shorts-studio/episodes/<회차폴더>`. Vrew 작업은 [VREW-GUIDE.md](VREW-GUIDE.md)를 보면서 `vrew.md`를 따라 하면 됩니다.

## 서브에이전트 분담 (`.claude/agents/`)

| 단계 | 에이전트 | 하는 일 |
|---|---|---|
| 1 | `shorts-trend-researcher` | 최근 2~4주 5060 관심 키워드 TOP 10 + 근거 URL |
| 2 | `shorts-planner` | 주제 3안 → 1안 확정, 첫 3초 후킹, 완주율 중심 구성 |
| 3 | `shorts-scriptwriter` | 장면별 원고 + Vrew 붙여넣기용 순수 원고 |
| 3-1 | `shorts-fact-checker` | **사실 검증 게이트.** 모든 숫자·제도·효능을 공식 원문과 대조. 통과 전에는 다음 단계 불가 |
| 4 | `shorts-vrew-director` | Vrew 단계별 편집 지시서 (AI 목소리, 이미지, 자막 위치, 저작권 안전 BGM) |
| 5 | `shorts-growth-manager` | 제목·설명·해시태그·고정댓글·업로드 시간 |
| 5-1 | `shorts-growth-manager` (QA) | **업로드 전 QA 게이트.** [CHECKLIST.md](CHECKLIST.md) 판정 |
| 6 | `shorts-growth-manager` (회고) | 주 1회 성과 회고, 다음 주 키워드 조정 |

공통 기준은 [channel-profile.md](channel-profile.md)에 있습니다. 톤이나 금지 사항을 바꾸려면 이 파일만 고치면 됩니다.

자세한 순서는 [HOW-TO.md](HOW-TO.md) (같은 내용의 고정 페이지: https://claude.ai/artifact/9n37DebTLvR1jXQucHZnxh)

- 일: YouTube Studio에서 조회수·평균 시청률·구독 증가를 확인해 growth-manager에 주간 회고 요청

## 수익화 로드맵
1. **0~3개월 — 기반 쌓기**
   - 주 3~5편, 6개 분야(건강·재테크·노후 준비·여행·생활정보·최신 이슈)를 돌아가며 시리즈화
   - YouTube 파트너 프로그램(YPP) 조건 확인: 쇼츠 경로는 구독자 1,000명 + 최근 90일 쇼츠 조회수 1,000만 회가 대표 기준입니다.
     조건은 바뀔 수 있으니 YouTube 고객센터에서 최신 기준을 확인하세요.
2. **3~6개월 — 롱폼 확장**
   - 반응 좋은 주제를 5~10분 롱폼으로 확장해 시청 시간 확보 (롱폼 경로: 구독자 1,000명 + 최근 12개월 공개 시청 4,000시간)
3. **6개월~ — 수익 다각화**
   - 제휴 링크(쿠팡파트너스 등): 설명란·고정댓글에 광고 고지 필수
   - 협찬, 전자책·강의
   - 건강·금융 상품 제휴는 신뢰를 잃기 쉬우므로 신중하게

## 안전 원칙 (요약)
- 출처 없는 숫자는 쓰지 않습니다. 건강·금융은 면책 문구와 출처를 항상 넣습니다.
- 상용 음악, 방송 캡처, 타인 영상은 쓰지 않습니다.
- 조회수가 낮아도 삭제하지 않고, 문제가 있으면 비공개 처리 후 원인을 분석합니다.

# 업로드 전 QA 체크리스트

`shorts-growth-manager`가 QA 모드에서 항목별로 판정하고 결과를 `episodes/<회차>/qa.md`에 남깁니다.
Vrew 화면이나 휴대폰에서만 확인할 수 있는 항목은 **사용자 확인 필요**로 표시합니다.

## 후킹·구성
- [ ] 0~3초 안에 주제를 보여주는 큰 글자와 장면이 나온다 (인사·채널 소개 없음)
- [ ] 첫 나레이션이 0.5초 안에 시작된다
- [ ] 핵심 정보 3개 이하이고, 늘어지는 구간이나 같은 말 반복이 없다
- [ ] 첫 문장에 숫자가 있고, 면책 줄을 뺀 원고 줄의 절반 이상에 숫자가 있다 (비율은 돈으로 환산, 추상어 없음)
- [ ] 총 길이 30~60초

## 사실·정책
- [ ] `factcheck.md` 최종판정이 '통과'이고, 설명란에 출처가 있다
- [ ] 건강·금융 주제는 면책 문구가 있고, 단정·공포 표현이 없다
- [ ] 1년 뒤에 처음 본 사람에게도 맞는 내용이다 (마감일·행사 날짜·"지금/이번 달/올해" 표현 없음, 제목·제목 그림·고정댓글 포함)

## 숫자 카드
- [ ] 숫자 카드(표 이미지) 1장 이상이 있고, 모든 숫자가 factcheck.md에서 확인됐다 (계산 예시는 계산식 기록)
- [ ] 휴대폰에서 표 글자가 읽히고, 카드 장면의 자막이 표를 가리지 않는다

## 저작권
- [ ] BGM이 YouTube 오디오 보관함 또는 라이선스를 확인한 Vrew 음원이다 (출처 표기 조건 충족)
- [ ] 이미지·영상이 Vrew 제공 / 무료 라이선스 / AI 생성 중 하나다 (방송 캡처·타인 영상 없음)
- [ ] 업로드 후 YouTube Studio에서 '저작권 주장'이 없는지 확인했다

## 자막·화면
- [ ] 자막이 얼굴·핵심 화면(표, 숫자, 제품)을 가리지 않는다
- [ ] 자막이 쇼츠 UI(오른쪽 버튼, 아래쪽 제목·채널명)와 겹치지 않는다
- [ ] 한 줄 12자 이내, 색은 기본색 + 강조색 1개
- [ ] 휴대폰에서 실제로 재생해 글자 크기를 확인했다

## 운영
- [ ] 제목, 설명, 해시태그, 고정댓글을 입력했다
- [ ] 조회수가 낮아도 삭제하지 않고, 문제가 있으면 비공개 처리 후 원인을 분석한다
- [ ] 이전 영상과 같은 영상을 다시 올리지 않았다

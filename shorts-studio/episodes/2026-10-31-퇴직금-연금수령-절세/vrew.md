## 2. 단계별 지시서

### 1단계. 새 프로젝트 만들기 (9:16)
1. `새로 만들기`(새 영상 프로젝트를 시작하는 버튼) 클릭
2. `텍스트로 비디오 만들기`(대본을 넣으면 AI 목소리·이미지·자막을 자동으로 만들어 주는 기능) 선택
3. 화면 비율에서 `쇼츠 9:16`(세로 화면) 선택
- 자주 하는 실수: 16:9(가로)로 시작했다가 나중에 바꾸면 자막과 이미지 위치가 전부 틀어집니다. 처음부터 9:16으로 고르세요.

### 2단계. 비디오 스타일 선택 → 순수 원고 붙여넣기
1. `비디오 스타일`(이미지·자막 기본 모양 묶음)에서 차분한 정보형 스타일을 고릅니다. 화려한 효과나 이모지 스타일은 피하세요.
2. 대본 입력 칸에 `script.md`의 'Vrew 붙여넣기용 순수 원고 (v3)' 14줄을 붙여넣습니다(또는 자동 패키지의 `01_원고_붙여넣기.txt`). 한 줄이 한 장면이 되도록 줄바꿈을 그대로 둡니다.
3. 붙여넣은 뒤 첫 줄이 "퇴직금 세금 1,000만 원이 700만 원으로", 열셋째 줄이 "정리하면, 1,000만 원이 500만 원까지."인지 확인합니다. 그래야 v3입니다.
- 자주 하는 실수: 장면표의 나레이션을 복사하면서 장면 번호나 `|` 표시까지 붙여넣는 경우입니다. 순수 원고 코드 블록만 복사하세요.

### 3단계. AI 목소리
1. `AI 목소리`(나레이션 음성을 고르는 메뉴, 버전에 따라 '목소리 변경')에서 `미리 듣기`(샘플 재생)로 비교합니다.
2. 추천: **차분한 중년 남성 톤 1개, 또는 차분한 중년 여성 톤 1개**. 설명에 '차분한', '신뢰감', '뉴스·안내'가 붙은 목소리를 고르세요.
3. 속도 **0.95배** (0.9~1.0배 범위). `전체 적용`(모든 장면에 같은 목소리 적용)으로 한 번에 바꿉니다.
4. 발음 확인: "IRP"(아이알피), "30%", "40%", "50%", "55세", "10년째", "11년째", "21년째", "1,000만 원"(천만 원), "700만·600만·500만 원", "0원", "1가지"(한 가지)를 꼭 들어 봅니다. 어색하면 `발음 수정`(자막 글자는 그대로 두고 읽는 방식만 바꾸는 기능)으로 고칩니다.
- 자주 하는 실수: 장면 하나만 목소리를 바꿔 중간에 목소리가 달라지는 경우입니다. 반드시 전체 적용하세요.

### 4단계. 장면별 이미지
1. 장면을 클릭한 뒤 `이미지/비디오 교체`(그 장면 배경을 바꾸는 버튼) → `AI 이미지`(문장으로 그림을 생성) 또는 `무료 이미지`(Vrew 제공 사진·영상 검색)를 고릅니다.
2. AI 이미지는 자동 패키지의 `02_AI이미지_프롬프트.txt` 문장을 그대로 넣습니다. 무료 이미지는 편집표 키워드를 검색하고, 한국어 결과가 적으면 영어 키워드를 씁니다.
3. 장면 1은 위쪽 1/3이 복잡하지 않은(하늘, 흐린 배경) 이미지를 고릅니다.
4. 이미지에 글자·숫자·로고를 넣지 마세요. 은행 창구(장면 3)·전화 상담(장면 12)에 실제 금융회사 간판·로고가 보이면 다른 컷을 고릅니다. 실제 앱 화면, 뉴스 화면, 실존 인물은 쓰지 않습니다.
- 자주 하는 실수: 인터넷 검색 이미지나 금융회사 홈페이지 캡처를 넣는 경우입니다. 저작권과 특정 회사 홍보 문제가 생기므로 Vrew 무료 이미지나 AI 이미지만 쓰세요.

### 5단계. 자막 스타일
1. `서식` 또는 `자막 서식`(글꼴·크기·색·위치를 바꾸는 메뉴)에서 아래처럼 맞추고 `전체 적용`합니다.
   - 글꼴: 굵은 고딕 계열
   - 크기: 1080x1920 화면 기준 약 70~90px
   - 색: 흰 글자 + 검은 테두리(두께 4~6). 박스 배경은 쓰지 않습니다
   - 강조색: 연두(#7CF08A 부근) 1개만
   - 줄 길이: 한 줄 12자 이내 (편집표의 `/` 위치에서 줄을 나눔)
2. 위치: 화면 **아래쪽 1/3 위**, 위에서 약 65~72% 높이
   - 아래쪽 약 20%(제목·채널명 영역)와 오른쪽 끝 약 150px(좋아요·댓글 버튼)을 비워 둡니다
3. 장면마다 확인: 얼굴(장면 1, 2, 3, 12, 14)과 달력·저금통·계산기(장면 4, 10, 13)를 가리면 그 장면만 자막을 위아래로 옮깁니다.
4. 큰 글자 장면(2, 3, 4, 9, 10, 11, 13)은 큰 글자가 위쪽, 자막이 아래쪽에 있어 서로 붙지 않게 간격을 둡니다.
- 자주 하는 실수: PC에서는 충분히 커 보여도 휴대폰에서는 작습니다. 휴대폰으로 꼭 확인하세요.

### 6단계. BGM (배경음악)
1. 음원 고르기 (둘 중 하나):
   - **YouTube 오디오 보관함**: YouTube Studio → `오디오 보관함`(무료 음원 목록). 분위기 `Calm`(차분한), 장르 `Ambient`·`Classical`, 악기 `Piano`. 길이 1분 이상. 내려받은 mp3를 Vrew `삽입` → `배경 음악` → `내 PC에서 불러오기`로 넣습니다.
   - **Vrew 제공 음원**: `삽입` → `배경 음악` → Vrew 음원 목록. **상업적 이용 가능 여부**와 **출처 표기 필요 여부**를 확인할 수 있는 곡만 씁니다.
2. 분위기 키워드: `잔잔한 피아노`, `차분한 안내`, `가벼운 앰비언트`. 긴장감 있는 곡, 가사 있는 곡은 피합니다.
3. 라이선스 확인: YouTube 오디오 보관함은 곡 옆 `라이선스 유형`을 보고, 'Creative Commons 저작자 표시'이면 제공 문구를 그대로 아래 음원 기록란에 붙여넣습니다. Vrew 음원은 곡 정보·이용 안내 화면을 캡처해 둡니다.
4. 볼륨: 나레이션 대비 **10~15%**. 마지막 1초는 `페이드 아웃`(소리가 서서히 작아지는 효과).
5. 가요·트로트·방송 클립·다른 사람 영상의 소리는 쓰지 않습니다.
- 자주 하는 실수: 좋아하는 가요를 배경에 까는 경우입니다. 영상이 차단되거나 수익이 원저작자에게 갑니다.

### 7단계. 불필요한 구간 자르기
1. `무음 구간 줄이기`(말 없는 빈 시간을 자동으로 줄이는 기능, 버전에 따라 '공백 줄이기')를 실행합니다.
2. 장면 1 맨 앞 빈 시간을 지워 **0초에 바로 "퇴직금 세금"이 들리게** 합니다 (0.5초 이내).
3. 장면 7("11년째부터는 40% 줄어 600만 원,")과 장면 8 사이는 한 문장처럼 이어지게 끊김을 줄입니다. 장면 14(면책)는 끝에 약 1초 여유를 둡니다.
- 자주 하는 실수: 앞부분에 인트로 효과음이나 로고를 넣어 나레이션이 늦게 시작되는 경우입니다.

### 8단계. 첫 장면 큰 제목 (후킹)
1. 장면 1 선택 → `삽입` → `이미지`(PC의 그림 파일을 화면 위에 얹는 기능) → 자동 패키지 폴더의 **`title-overlay.png`**(투명 배경) → 화면 전체 크기로 맨 위에 얹습니다.
2. 내용: **퇴직금 세금 / 30% 덜 내는 법**, 태그 `55세 이후`, 둘째 줄과 태그가 연두색.
3. `애니메이션`(글자가 나타나는 효과)은 **없음**, 시작 시간 **0초**.
4. 장면 2, 3, 4, 9, 10, 11, 13의 큰 글자는 `삽입` → `텍스트`(화면 위에 글자 상자를 추가하는 기능)로 넣습니다. 위치(화면 위쪽 1/4~1/3, 맨 위 5%는 비움)와 크기(자막의 약 1.5배)를 통일하고, 흰 글자 + 검은 테두리 + 연두 강조색으로 맞춥니다.
- 자주 하는 실수: "충격", "모르면 손해" 같은 낚시 문구를 임의로 덧붙이는 경우입니다. 팩트체크를 통과한 문구만 씁니다.

### 9단계. 미리보기로 길이 확인
1. `미리보기`(완성 영상을 처음부터 재생)로 끝까지 봅니다.
2. 전체 길이가 **30~60초**(예상 약 50~54초)인지 확인합니다.
3. 60초를 넘으면 속도를 1.0배로 올립니다. 그래도 넘으면 원고를 줄이지 말고 멈춥니다 (원고를 바꾸면 팩트체크를 다시 받아야 합니다).
- 자주 하는 실수: 속도를 1.1배 이상으로 올려 길이를 맞추는 경우입니다. 중장년 시청자가 따라오지 못합니다.

### 10단계. 내보내기
1. 오른쪽 위 `내보내기`(완성 영상을 파일로 저장) → `영상 파일(mp4)`
2. 해상도 **1080x1920** (목록에 '1080p'로 보이면 세로 9:16인지 확인)
3. 저장한 파일을 휴대폰으로 옮겨 끝까지 재생합니다. 글자 크기, 자막 가림, BGM 크기를 봅니다.
4. 업로드 직전에 기획재정부 2025년 세제개편안 상세본 p.44(https://www.korea.kr/briefing/pressReleaseView.do?newsId=156713628 첨부)와 국가법령정보센터 소득세법 제129조를 직접 열어 30%·40%·50% 감면 구조가 그대로인지 확인합니다. 팩트체크에서 법령 원문은 접속 차단으로 직접 대조하지 못했습니다.
- 자주 하는 실수: 720p나 워터마크가 붙은 채로 내보내는 경우입니다.

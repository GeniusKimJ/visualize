## 변경 목록 (v1 15줄 → v2 12줄)
1. 첫 줄: "부모님 병원비, 세금에서 돌려받을 수 있어요."(숫자 없음) + "연말정산 의료비 세액공제예요."를 **"연말정산, 부모님 병원비도 15% 공제돼요."** 한 줄로 합침 → 첫 문장에 숫자(15%), 제목 카드 "부모님 병원비 / 15% 세액공제"와 같은 말. 바로 다음 두 줄이 '3% 넘는 금액의 15%'로 조건을 붙임.
2. "보통 부양가족은 700만 원까지만 인정되는데" + "65세 이상 부모님은 한도가 없어요."를 **"65세 이상은 700만 원 한도도 없어요."** 한 줄로 합침 (숫자 2개).
3. 숫자 카드 장면 3줄 → 표를 짚는 말 + 입력/결과 금액을 나란히: "표를 보시면 병원비 500만 원일 때" + "공제받는 세금은 52만 5천 원이에요." → **"표처럼 500만 원이면 52만 5천 원,"** / "1,000만 원이면 127만 5천 원이고요." → **"1,000만 원은 127만 5천 원 공제돼요."** (15%를 돈으로 환산, 병원비 → 공제액 두 숫자를 나란히)
4. "간소화 자료를 꼭 확인해 보세요."(숫자 없음) → **"3% 넘는 병원비, 15% 꼭 챙기세요."** (행동 권유 + 면책 바로 앞 핵심 숫자 반복). 간소화 자료 확인 안내는 설명란에 그대로 남김.
5. 유지: "1년 의료비가 총급여의 3%를 넘으면", "넘은 금액의 15%를 세금에서 빼 줘요.", "총급여 5천만 원이면 기준은 150만 원.", 조건 3줄(실손·직접 부담·소득 무관), 면책 줄.
6. 길이: 260자 → 216자(약 53~58초 → 약 48~52초). 숫자 줄 7/14 → 8/11.

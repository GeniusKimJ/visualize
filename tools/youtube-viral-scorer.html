YouTube 떡상 스코어러

YouTube Data API v3로 영상을 모아 구독자 대비 조회수, 일평균 조회수, 참여율을 점수로 매깁니다.

1. API 키

키 발급: Google Cloud Console에서 "YouTube Data API v3"를 사용 설정한 뒤, 사용자 인증 정보에서 API 키를 만드세요. 하루 무료 할당량은 10,000유닛이고, 키워드 검색 1페이지(50개)에 약 102유닛이 듭니다. 키는 브라우저에서 Google로 바로 전송되며 다른 곳으로는 보내지 않습니다.

2. 영상 수집

키워드 검색
채널 분석
URL 직접 입력

채널 모드에서는 구독자 수가 모든 영상에 같으므로, 떡상지수는 채널 안에서의 상대 비교로 보세요.

3. 점수 가중치

떡상지수 점수 = log10(조회수/구독자 + 1) ÷ log10(101) × 100  → 구독자의 100배면 100점
속도 점수 = log10(일평균 조회수 + 1) ÷ 6 × 100  → 하루 100만 회면 100점
참여율 점수 = 참여율(%) ÷ 8 × 100  → 8%면 100점 (상한 100)
종합 = 가중 평균  |  등급: S ≥ 85, A ≥ 70, B ≥ 55, C ≥ 40, 나머지 D
